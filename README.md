# projet3-Requetez-une-base-de-donnees-avec-SQL

## 🎯 Contexte
Mission pour une entreprise du secteur de l'assurance habitation. L'objectif est d'analyser le marché des assurances en créant et en requêtant une base de données SQL.

## 📚 Compétences développées
- Charger des données dans une base de données
- Créer un schéma de base de données relationnel
- Rédiger des scripts SQL pour aider à la prise de décision business

## 🧠 Ce que j'ai appris
Ce projet m'a permis de maîtriser la modélisation relationnelle et la rédaction de requêtes SQL : sélections, jointures, agrégations et filtres. J'ai appris à traduire une question métier en requête SQL exploitable.

## 🗂️ Livrables
- Schéma de base de données (modèle relationnel)
- Scripts SQL commentés
- Présentation des résultats d'analyse

## 🔧 Outils utilisés
SQL , EXCEL
